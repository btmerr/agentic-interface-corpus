Tuesday brief — approvals and spatial/timeline legibility (chat stays intake):

1. **[Human-in-the-Loop: Where to Put the Approval Gate](https://multigrid.ai/learn/human-in-the-loop-agents)** — Multigrid  
   Plan approval = scope confirmation, not authorization; bind to hashed resolved args; gate by blast radius.  
   **Credibility: High** — sharp eng practice.

2. **[AI Action Review Pattern](https://uipotion.com/potions/patterns/ai-action-review)** — UI Potion  
   Typed action items, risk labels, approve-selected, pause/stop/undo, audit trail — separate from chat chrome.  
   **Credibility: Medium–High** — unusually complete pattern library.

3. **[Building a human-in-the-loop approval queue](https://theagentpractice.com/blog/ai-agent-approval-queue-pattern)** — The Agent Practice  
   Before/after snapshots, execute-on-approve, reject-requires-note, demotion ladder as trust compounds.  
   **Credibility: High** — concrete schema + UX rules.

4. **[Agent Flow](https://github.com/patoles/agent-flow)** — patoles  
   Node graph of branching/subagents, timeline, file-attention heatmap — black-box CLIs made watchable.  
   **Credibility: Medium–High** — shipped OSS from real debugging pain.

5. **[Agor](https://agor.live/guide)** — agor.live  
   Multiplayer spatial canvas; agents on isolated branches/zones with structured tool blocks.  
   **Credibility: Medium** — early product surface; steal the interaction model, not scale claims.

6. **[cctrace](https://github.com/thevibeworks/cctrace)** — thevibeworks  
   Human-turn reconstruction, trajectory bar, tool rows naming files, live replay — what a harness trace UI should feel like.  
   **Credibility: Medium** — niche tracer; informs display-state craft.

**Take:** Approvals as **typed review objects** (exact args/diffs, undo or demotion). Long runs as **spatial graph or trajectory timeline**. Cockpit paints state; chat is just intake.
