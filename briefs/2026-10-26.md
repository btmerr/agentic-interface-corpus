# Agentic & AI interface brief — 2026-10-26

**Theme: What the surface leaves out decides the outcome.**

1. **[Knowing When to Stop: The Evidence-Action Gap in Coding Agents (ImpasseBench, arXiv 2610.31895)](https://arxiv.org/abs/2610.31895)**
   ImpasseBench injects 12 realistic environment blockers and marks when evidence becomes sufficient for handoff. Across 8 models / 19,371 trajectories, a third still exhaust budget and all detected unsafe requests come after that point. An escalation tool cuts budget exhaustion 34.0% to 6.7%; a monitor nearly triples success after restoration. Handoff tickets name the blocker but omit progress and verification status. Harness: first-class 'I'm blocked' escalation with a structured handoff report. Credibility: medium-high. Authors include Tongshuang Wu; 8 models, 19,371 trajectories. Weight: high.

2. **[Who Verifies the Tools? How Warped Formatters Mislead Agents and Their Verifiers (arXiv 2610.32110)](https://arxiv.org/abs/2610.32110)**
   Tool output formatters that omit search limits, result caps or namespaces mislead both agent and verifier even when the tool is correct; one test flipped verifiers from accepting wrong answers 90/90 to rejecting 90/90 by fixing wording. Audit prompt found warped formatters in OpenClaw and Hermes (OpenClaw fix merged). Harness: tool results must state their truncation/caps/scope, and the UI should show them. Credibility: medium. Single author, production case + controlled tests; exploratory audit. Weight: medium-high.

3. **[Compact-Bench: Measuring What Context Compaction Costs Long-Horizon Coding Agents (arXiv 2610.31710)](https://arxiv.org/abs/2610.31710)**
   Paired full-history vs summary-only continuations: summarizers damage 5-64% of successes; LLM summaries keep at most 16% of recurring details vs 79.1% for mechanical extraction; production summaries keep 15.7% at first boundary. Harness: make compaction a visible, inspectable event with what was dropped, and pin task-progress state mechanically. Also: https://github.com/cai-jianfeng/compact-bench. Credibility: medium. USTC group; code and data released. Weight: medium-high.

4. **[ABRA: Agent-Bound UI for Human-Agent Communication beyond Chat with Reusable Views (arXiv 2610.30780)](https://arxiv.org/abs/2610.30780)**
   Separates reusable interaction structures from task-specific meanings: agents bind meanings to reusable views and publish bindings as shared state, so humans and agents act on the same canvas. Evaluated four LLM agents on canvas authoring, consequence resolution, cross-agent invocation. Harness: a reusable-view + binding model for non-chat surfaces. Also: https://github.com/megagonlabs/abra. Credibility: medium. Megagon Labs prototype; demo-level evaluation. Weight: medium.

5. **[ACP session/status liveness check RFD (PR #986, merged) + RFD PRs #2482 subagent model, #2485 token usage](https://github.com/agentclientprotocol/agent-client-protocol/pull/986)**
   session/status is a side-effect-free probe returning live/not_found, so a client or router can check liveness before load/prompt (merged 2026-10-26). #2482 (open) has agents report each subagent's model as a config option; #2485 (open) defines per-turn, in-turn, subagent and cumulative token usage. Harness: fleet views get liveness, per-child model and honest usage numbers from the protocol. Also: https://github.com/agentclientprotocol/agent-client-protocol/pull/2482, https://github.com/agentclientprotocol/agent-client-protocol/pull/2485. Credibility: high. Primary protocol repo; #986 merged, #2482/#2485 open RFD drafts. Weight: medium-high.

6. **[StateMirror: Pre-Execution Detection of Hallucinated Tool Calls in Coding Agents (arXiv 2610.32648)](https://arxiv.org/abs/2610.32648)**
   Intercepts actions at the harness boundary, extracts state predicates (paths, packages) via AST/command analysis, validates deterministically against the live repo: 0.940 precision, 1.5 ms vs 17.7 s for an LLM judge, zero tokens; agents fix >95% of flagged calls; live use cuts time 15.8% and tokens 11.8%. Harness: cheap deterministic pre-flight checks before every tool call. Credibility: medium. Academic group; deterministic checker evaluated on 2,508 actions, 79 live tasks. Weight: medium.
