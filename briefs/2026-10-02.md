# Agentic & AI interface brief — 2026-10-02

**Theme:** The plan is the approval surface. Make the plan a durable, line-anchored review object (not a chat blob); exit plan mode by ending the stream so approval is non-blocking; enforce a recorded plan artifact before mutation even under yolo; and at the execution boundary prefer revise/escalate over allow/deny-only.

1. **[Plan Mode — Command Code](https://commandcode.ai/docs/plan-mode)** — GitHub-style plan review as the gate  
   Read-only explore, then `exit_plan_mode` opens a persistent plan reader: one line always selected, Figma-style inline comments in a sidecar (not written into the plan), `ctrl+r` submit / `ctrl+a` approve / `esc` cancel. Revised rounds diff green against the prior snapshot so you re-read only what moved. Plans live under `~/.commandcode/plans/` with status badges and a `/plans` browser. Harness backstop: if a weak model writes a plan and stops, the review panel still appears. Complements yesterday’s AgentScope capability-denied plan phase with the actual review UX that makes the plan the approval prompt.

2. **[Plan Mode & Approvals — agent-desktop](https://www.agent-desktop.wiki/page.php?p=13-plan-mode)** — non-blocking structural exit  
   Intercepts `ExitPlanMode`, renders markdown Approve / Reject+feedback inline, then **ends the stream** — conversation goes idle; your reply is a new turn. Closing the app mid-pending is safe. Plan permission mode is a lockdown (only `exit_plan_mode` until you reply), distinct from the legacy Bypass+`ai_requirePlanApproval` intercept that shares the same card. Same family as Helix’s durable suspend, packaged as plan-exit UX: don’t park a sync waiter on the approval card.

3. **[Plan-first enforcement — go-steer/core-agent](https://github.com/go-steer/core-agent/blob/main/docs/plan-first-design.md)** — gate, not AGENTS.md hope  
   Shipped: `record_plan` always-allowed escape valve + `RequirePlanArtifact` / three-valued `permissions.plan_mode` (`off|advisory|required`). Write/exec/spawn denied until a plan file exists under `.agents/plans/`; reads stay open for research. Holds even in `yolo`. `/replan` clears the flag and revokes the artifact for audit. Complements AgentScope’s tool allow-list and yesterday’s steerability-via-constraints: the substrate guarantees “you see a plan before any mutation,” independent of instruction compliance.

4. **[Organizational Control Layer (OCL)](https://arxiv.org/abs/2606.04306)** — Shi et al.; approve / revise / block / escalate  
   Model-agnostic layer between proposal generation and environment-facing execution. On AgenticPay-style adversarial buyer–seller tasks: unsafe executions 88%→0%, valid success 12%→96%; ablations show blocking-only is safe but recovers far fewer valid deals than revise+escalate. Complements AWS Control-Surface Band with a four-outcome vocabulary and empirics that allow/deny alone is not enough — recovery is part of the gate.

5. **[PlanGate](https://github.com/s977043/PlanGate)** — dual fixed human gates on a coding harness  
   Governance-first Claude Code workflow: C-3 (plan APPROVE / CONDITIONAL / REJECT before any impl) and C-4 (PR review after TDD + auto-verify). Persistent `docs/working/TASK-XXXX/` artifacts (plan, todo, acceptance tests, handoff). “No approval, no code” as process substrate rather than a single tool interrupt — useful checklist for when plan review and PR review are deliberately separate control surfaces.

6. **[Modern Agent Harness Blueprint 2026](https://gist.github.com/amazingvince/52158d00fb8b3ba1b8476bc62bb562e3)** — architecture checklist, not a product  
   Practical synthesis: runtime / context / capability / governance / surface adapters; cache-stable prompt layout; artifact-first working memory; risk-tiered tools; MCP≠ACP≠A2A layering; anti-patterns (dynamic tool rewrite mid-session, model as sole enforcer). Use as a design checklist against your own harness — credibility is synthesis-of-docs, not a shipping eval.

**Takeaway for a non–chat+diff harness:** Stop treating the plan as transcript wallpaper. Persist it, review it like a PR (line comments + round diffs), exit plan mode without a sync hang, enforce the artifact in the gate before mutation, and at action time give the control layer revise/escalate — not only allow/deny.
