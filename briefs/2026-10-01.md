# Agentic & AI interface brief — 2026-10-01

**Theme:** Gates below the transcript. Plan as a capability-denied phase the model cannot exit alone; a governance band that evaluates before dispatch; fleet tables that join worktree/PR/ticket/presence instead of more chat panes; durable stream approvals; substrate constraints that shrink what supervision chrome must babysit.

1. **[Plan Mode — AgentScope Java](https://java.agentscope.io/v2/en/docs/harness/plan-mode.html)** — shipping harness phase, not a prompt  
   Read-only phase: only read tools + `plan_enter` / `plan_write` / `plan_exit` / `todo_write`; everything else denied with a synthetic note. Exit reuses the permission ASK — the model cannot unilaterally leave. Dedicated `plan_write` avoids whitelisting generic `write_file`. Honest about shell dual-use: default deny; opt-in softens to prompt-only read-only. Complements yesterday’s Grida normative plan↔build: middleware you can call, with admin enter/exit endpoints and persisted `AgentState`.

2. **[Steerability via constraints](https://arxiv.org/abs/2607.02389)** — Winninger; ICML DL4C’26  
   Oversight bottleneck, not capability. Transfer access control, network policy, and tooling-enforced conventions to agents — cheaper in tokens than more agentic scaffolding. Controlled study: small reviewer finds 11 planted Python backdoors; recall 54.5% → 90.9% with constrained substrate + ~200-LoC `docs` CLI; substrate and tools contribute independently. Design implication: shrink the blast radius so the supervision UI reviews less, not denser approve dialogs.

3. **[The Control-Surface Band](https://awslabs.dev/architecting-autonomy/control-surface-band/)** — AWS Architecting Autonomy; [sample-agentic-fabric](https://github.com/aws-samples/sample-agentic-fabric)  
   Insert a structural point between `bedrock.converse()` tool selection and SQS dispatch. Arbiter-level band before agent invoke; Worker-level `GovernedToolHandler.preprocess()` before each tool. One DynamoDB ledger; write-failure halts dispatch (no silent ungoverned action). Deny/escalate feed back as tool results — governance is observable environment, not a side channel. Complements cloudpresser’s control-surface thesis with a fail-closed production seam.

4. **[Cockpit](https://github.com/khivi/cockpit)** — one row per change (worktree · terminal · PR · ticket)  
   Orchestrates *context*, not agents. Live keyboard table joins git worktree, Claude Code session, GitHub PR, and Linear/Jira/Trello; re-derives every cycle so state cannot drift. `cockpit new` from branch/PR/issue/ticket/Slack permalink materializes the rest; nudge only into sessions parked at prompt. Distinct from yesterday’s ACP Fleet Commander: change-lifecycle join table for parallel human+agent work, not a protocol client.

5. **[Lakitu](https://github.com/dac2k9/lakitu)** — fleet cockpit over a shared coordination store  
   TUI + MCP + optional `serve` daemon: presence (working / needs-you / waiting-on-peer), per-agent inboxes, compaction-surviving tasks, personas, optional Projects v2 board tools. Agents write the store; you watch one screen — including a read-only web cockpit on loopback. Pair with Cockpit: Lakitu is agent-presence/coordination; Cockpit is change/worktree/PR join. Early Rust crate on crates.io; APIs may move.

6. **[Approval Gates — Helix Agents](https://agents.open-source.onhelix.ai/guide/approval-gates)** — declarative HITL at the tool-call boundary  
   `requireApproval: true` (or predicate) → validate input → emit `tool_approval_request` → suspend with durable `pendingClientToolCalls` → resume on `approval-response`. Function form fail-closes to require approval on throw. AI SDK UI parts + `addToolApprovalResponse`. Replaces hand-rolled confirmation tools with a first-class stream/suspend contract — same family as TanStack/AG-UI interrupts, packaged as the gate itself.

**Takeaway for a non–chat+diff harness:** Put the hard gate under the transcript — capability regimes, pre-dispatch governance, join tables for fleet attention, durable approval suspends. Prefer substrate constraints that make review cheap over denser chrome that still watches unconstrained agents.
