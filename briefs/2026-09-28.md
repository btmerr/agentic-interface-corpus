# Agentic & AI interface brief — 2026-09-28

**Theme:** Staged supervision over a durable harness. Chat for intent; the product is stages (plan→wait→review→assets), shared graphs, learned check-ins, and phone-reachable gates.

1. **[ASD: Agentic AI Harnesses](https://www.cyber.gov.au/business-government/secure-design/artificial-intelligence/agentic-ai-harnesses)** — Australian Signals Directorate (11 Sep 2026)  
   Harness = body, LLM = brain. UI, permissions, tool registry, sandboxes, and audit are where org risk and investment actually live. Treat supervision chrome as security architecture.

2. **[The Work Behind Delegation](https://arxiv.org/abs/2609.24234)** — Park et al., KAIST/CMU  
   Seven supervisory stages: Plan · Monitor · Wait · Review · Teach · Manual Fix · Update Assets. Wait ≠ Monitor; learn becomes Update Assets (`AGENT.md`, skills). Map your harness surfaces to these stages—don't collapse them into one Plan Mode modal.

3. **[Vibe-GUIDE](https://arxiv.org/abs/2609.23859)** — Chou et al., UC Davis / Oregon State  
   Live functional-module graph beside chat: structural, live, manipulable, adaptive. Graph for orientation and change-tracking; chat still directs. Relationship comprehension + steadier pace across cumulative tasks. Shared representation beats transcript archaeology.

4. **[Hedwig](https://arxiv.org/abs/2605.11495)** — Shukla et al. (UW); [CLI](https://github.com/tanjalshukla/HedwigCLI)  
   Autonomy that learns from approve/deny/edit traces. Hard constraints vs soft guidance; policy- vs agent-initiated check-ins reported separately. Interrupt budget as a first-class, inspectable control surface.

5. **[Claude Code on mobile](https://code.claude.com/docs/en/mobile)** — Anthropic docs  
   Code tab: cloud sessions, Projects (parallel threads), Remote Control of a local machine, Dispatch + push when a decision is needed. Supervision leaves the desk. Caveat: permission modes are constrained on phone—gates still need enough payload that a remote approve/deny is a real decision, not theater.

6. **[Agentic Control Plane — phone approvals](https://agenticcontrolplane.com/blog/approve-coding-agent-commands-from-your-phone)** — Crowe, 24 Sep 2026 ([docs](https://agenticcontrolplane.com/docs/approvals))  
   Cross-harness allow/deny/ask by tool × tier; held calls → email + phone console; silence expires as deny; answers graduate to standing rules. Overnight fleets need a reachable approval queue, not a stuck terminal prompt.

7. **[A2UI v0.9.1](https://a2ui.org/specification/v0.9.1-a2ui/)** — Agent-to-UI protocol  
   Streaming surfaces: create / update components / update data / delete. Catalog-negotiated UI the agent can emit; binds over A2A, AG-UI, MCP. Review packets and gates as real UI, not Markdown cards.

**Takeaway for a non–chat+diff harness:** Build stage-aware surfaces (incl. Wait + Update Assets), a live shared project graph, a learned interrupt policy, and a phone-reachable approval queue—then let protocols like A2UI carry the review objects.
