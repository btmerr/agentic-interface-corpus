# Agentic & AI interface brief — 2026-11-06

**Theme: A receipt licenses one named property — not the world.** Today's items all puncture unqualified guarantees: a fork is not environment-safe, a signature is not intent-faithful, an MCP "done" is not feasible, and cancelling one agent is not containment. For a non-chat harness, every control (fork, approve, replay, contain, score) needs an explicit property and an evidence boundary.

1. **[Replay Is a Family of Assertions: Fork-Safety in Event-Sourced Agent Runtimes](https://arxiv.org/abs/2611.06924)** (arXiv 2611.06924), a fork is Sound for one property and Unsound for another
   Event-sourced harnesses sell "deterministic replay" and "cheap forks" as one feature. This paper splits them into seven assertions (byte/trace/projection/path/decision/execution/environment) and shows a cut can be Sound for projection while Unsound for continuation or a counterfactual world. Across 5,540 public logs, all 317,296 ProjectionReplay cuts are Sound, while ExternalContinuation has 36,251 Unsound cuts (exactly the open LLM-request boundaries) and 120,969 Conditional ones that must serve recorded oracles without re-execution. Your fork/rewind UI should return Ok / Refuse / Conditional(obligation), not a single "safe." Credibility: medium-high (Untapped Capital / activegraph.ai; executable F# contracts; named counterexamples; ActiveGraph-family corpus limit stated). Weight: high.

2. **[Call-Level Revision Contracts for LLM-Authored Workflows](https://arxiv.org/abs/2611.06967)** (arXiv 2611.06967), freeze the committed call expression — leave the surrounding code writable
   When the model rewrites orchestration after a mid-run failure, durable engines replay by command sequence and miss payload edits or helper moves. Structural identity ι=(callsite, fanout path, occurrence) plus a static gate and payload digest freezes committed call expressions while leaving surrounding code writable. Gate-passed repairs replay 258 committed identities with 0 duplicates; a live six-way fanout makes 7 paid calls vs 12 on a full rerun; relocating a committed call into a helper is stopped before spend (Temporal reset completes the same repair in 7 attempts). For your harness: make approve/repair a contract over frozen call identities, not a chat edit of the plan. Credibility: medium-high (SCNU; Temporal + DBOS comparisons; live image providers; Proposition 4 proves no local identity is both relocation-invariant and free of wrong reuse). Weight: high.

3. **[Signed but Not Safe: Requirement Integrity in Multi-Agent LLM Handoffs](https://arxiv.org/abs/2611.07483)** (arXiv 2611.07483), HMAC authenticates whatever was extracted — including the attacker's version
   Complements yesterday's germline MCP paper: HMAC on a requirement manifest defeats in-transit tampering by construction, but extraction is the trust boundary. Under attack, signed vs structured unsafe commits fall from 69.4% to 9.0% (60.4 pp); signing vs unsigned under mutation is 79.2 pp. A deterministic verifier catches 78.7% of violating decisions vs 59.0% for a shadow LLM checker. Pre-signing injection raises signed violations (Qwen 14.6%→37.5%; gpt-oss 11.1%→63.9%), and every signed violation had a corrupted manifest. Sign after user/confirmable extraction; verify decisions in code. Credibility: medium-high (UMass/Accentrust/Duke/UIUC; preregistered Holm family; synthetic finite-domain tasks). Weight: high.

4. **[Codex CLI 0.167.0 — unread markers + inline patch review during approval](https://github.com/openai/codex/releases/tag/rust-v0.167.0)**, shipping craft for a non-chat control surface
   Official OpenAI Codex release (2026-11-06). Agent command center + session picker mark unread results; expand patch details in the transcript while an approval prompt is open; network approval prompts close when requests end and serialize concurrent same-endpoint prompts; switch connected backends while preserving drafts. Docs cover `[permissions.network]` managed constraints and `prompt-user` rules that require fresh human approval. (Command center existed since ~0.162; this release makes unread + approval-inline review first-class.) Credibility: high (official release notes). Weight: high.

5. **[MCPHallu: Benchmarking Reasoning, Execution, and Memory Hallucinations in MCP Agents](https://arxiv.org/abs/2611.07689)** (arXiv 2611.07689), Unreachable Goal is the killer — more tool calls are not recovery
   Task-success MCP benches hide *why* agents fail. MCPHallu forces subtype triggers (Branch Collapse, Unreachable Goal, Tool Misuse, Context Forgetting) on 36 live servers across 358 tasks / 5,012 trajectories. Mean score 0.642 (best 0.728); Unreachable Goal mean 0.458 with 23.2% pass; ≥4 tool calls on Unreachable Goal → 0% pass, while completion-language rises with call count. Tool Misuse: correct-only 84.7% pass vs correct+confusion 32.3%. Your surface needs an explicit "infeasible / stop" verb and should not treat more tool calls as recovery. Credibility: medium-high (PKU / Zhongguancun / Meituan / HKUST; subtype targeting κ=0.78; judge weight bounded 20–30%). Weight: medium-high.

6. **[Airlock: Bounding the Multi-Agent Blast Radius via Selective Online Containment](https://arxiv.org/abs/2611.06727)** (arXiv 2611.06727), cancel-the-agent misses consumers that already read bad output
   Fleet supervision: cancelling the faulty agent misses peers that already consumed its output; halt-everything destroys healthy work. Airlock pairs permission-narrowing runtime (EdgeCitadel) with a provenance DAG and fence-then-prune min-cut. Blocks all post-alert faulty actuations on main grids with 0 post-τ₁ leaks; retains +68 to +96 pp more healthy work without redo vs A2A/LangGraph leak-free baselines; optimized cut +46 pp vs full quarantine under dense spread. Your multi-agent control plane needs forward taint + per-object switches (hold/revoke egress), not only "stop agent." Credibility: medium-high (Imperial/Oxford; 1,832 testbed + 161 physical smart-home LLM runs + 24,266 sims; OpenAI–Hugging Face incident as motivation). Weight: medium-high.

7. **[ACP PR #2765: stabilize client-provided system prompt](https://github.com/agentclientprotocol/agent-client-protocol/pull/2765)**, interface policy injection is now a stable contract
   Moves Client-Provided System Prompt from Preview → Completed. `SystemPrompt`, `SystemPromptMode`, capabilities, and `systemPrompt` on session/new|load|resume are stable in v1 and v2; `session/fork` systemPrompt stays behind `unstable_session_fork`. Docs add System prompt sections, −32602 invalid-params guidance, and prompt-injection trust guidance. Claude Agent ACP and Codex ACP adapters cited as implementers. For a harness that injects modes/trust/non-chat instructions via ACP, this is the shipping event (the RFD was already Draft in corpus). Credibility: high (official ACP merge by maintainer benbrandt). Weight: medium-high.

**Takeaway for a non-chat+diff harness:** Name the property each control claims (projection vs continuation vs environment; frozen call vs writable surround; transit integrity vs extraction fidelity; infeasibility vs more tools; contain reach vs cancel agent). Return Ok / Refuse / Conditional with evidence boundaries. Sign after confirmable extraction. Give Unreachable Goal an explicit stop verb. Contain by provenance reach, not by stopping one process.
