Thursday brief — plan as a versioned review object, and supervision metaphors that aren’t IDE chrome:

1. **[Plan. Approve. Ship.](https://continuumcode.ai/product/plan-review/)** — Continuum  
   Approve = **respawn with write perms**, not “resume with more trust”; plan card as shared contract across agent shapes.  
   **Credibility: High** — primary product craft; steal the seam.

2. **[Agent Cockpit](https://agent-cockpit.dev/docs)** — agent-cockpit  
   Pixel-art office map as attention layer; floating Approvals / Timeline / Diff / Memory; keyboard risk-sorted approvals.  
   **Credibility: High for interaction model** — primary OSS; early/playful, concrete craft.

3. **[Lodestar](https://github.com/builder-seoro/Lodestar)** — builder-seoro  
   Decision cards + UX shape-lock **before** code; Guided vs Express; completeness gates over vibe loops.  
   **Credibility: Medium–High as design brief** — real artifact contract; early stars.

4. **[Agent plan preview](https://uxpatternsguide.com/patterns/agent-plan-preview/)** — UX Patterns Guide  
   Plan version, editable/fixed/blocked/stale steps; prove execution matched the reviewed version.  
   **Credibility: Medium–High** — complete pattern checklist.

5. **[omp-deck](https://www.npmjs.com/package/omp-deck)** — Bryan Bartley  
   Kanban the agent can mutate, plan approve/edit/reject in web UI, routines on a node canvas.  
   **Credibility: Medium–High** — real self-hosted cockpit; layout reference.

6. **[Agent mode and Plan mode — CoCo Desktop](https://docs.snowflake.com/en/user-guide/cortex-code/cortex-code-desktop/agent-mode-and-plan-mode)** — Snowflake  
   Enterprise shipping the same two-pole model: Plan read-only → card + Build; proposed mode switches with confirm.  
   **Credibility: High** — primary vendor docs; proves the seam is table stakes.

**Take:** Plan is an object with a **version and a hard permission boundary**. Borrow Continuum/CoCo’s seam *and* Cockpit/Lodestar/omp-deck’s attention metaphors. Chat stays intake; the cockpit owns consent and attention.
